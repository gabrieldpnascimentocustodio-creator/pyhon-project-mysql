<h1>👥 Person Management System</h1>

A simple person management application built with Python and MySQL. This project implements basic CRUD operations, allowing users to register, list, search, and delete records through a command-line interface.

The project was developed to practice Python programming, database integration, SQL queries, input validation, and application logic.

🚀 Features

Create: Register new people in the MySQL database.

Read: Display all registered people.

Search: Find a person using their ID.

Delete: Remove a person from the database.

Name Validation: Prevent empty names and whitespace-only entries.

Email Validation: Check email format using Python Regular Expressions (Regex).

SQL Parameterization: Use parameterized queries to help prevent SQL Injection.
